# 동해시 공식 CI

엔드 카드의 로고 자리에 쓰는 파일입니다.

- `donghae_ci.png`: 받으신 동해시 공식 CI(흰 바탕 JPG, 567×567)에서 둘레의 흰 여백만 잘라(x 81–486, y 102–465, 405×363) PNG로 저장한 것입니다. 다시 그리거나 색을 바꾸지 않았습니다.
- 엔드 카드에서는 기관명 바로 위 흰 판(모서리 둥근 판, 옅은 그림자)에 놓입니다. 세로형 로고라 세로 168px 안에 맞춥니다.
- 깃발 판매처 그림에서 오렸던 임시 로고는 지웠습니다.

더 큰 원본을 받으면:

1. PNG(흰 바탕 또는 투명 바탕, 가로 600px 이상)로 이 폴더에 `donghae_ci.png`라는 이름으로 바꿔 넣습니다. AI 파일은 PNG로 바꿔서 넣으면 됩니다(EPS는 그대로 쓸 수 없습니다).
2. `animatic_36s.html`을 다시 열면 같은 자리에 맞춰 들어갑니다. 기관명과 문의번호의 자리는 그대로입니다.
3. MP4를 다시 뽑으려면 `README.md`의 ‘MP4로 뽑기’를 따릅니다.
