# 동해시 공식 CI 넣는 곳

엔드 카드의 로고 자리입니다. 지금은 비어 있고, 영상에도 로고가 나오지 않습니다(깃발 판매처 그림에서 오렸던 임시 로고는 지웠습니다).

1. 동해시청 누리집이나 담당 부서에서 공식 CI 파일을 받습니다.
2. PNG(흰 바탕 또는 투명 바탕, 가로 600px 이상)로 저장해 이 폴더에 `donghae_ci.png`라는 이름으로 넣습니다.
   AI 파일은 PNG로 바꿔서 넣으면 됩니다(EPS는 그대로 쓸 수 없습니다).
3. `animatic_36s.html`을 다시 열면 기관명 바로 위에 흰 판과 함께 들어갑니다. 파일은 다시 그리거나 색을 바꾸지 않고 그대로 씁니다.
   로고가 들어와도 기관명과 문의번호의 자리는 그대로입니다.
4. MP4를 다시 뽑으려면 `README.md`의 ‘MP4로 뽑기’를 따릅니다.
